Eagle GD - M3 (speech input) - how to apply
============================================

Run these in PowerShell from the project folder:
    cd "C:\Users\softw\Past_Projects\Eagle Group Discussion"

0. Save M2 first (skip if already committed):
    git add .
    git commit -m "M2: speech output complete (QMediaPlayer queue)"

1. Copy the files in (the zip is assumed to be in Downloads):
    Expand-Archive -Path "$env:USERPROFILE\Downloads\Eagle_M3.zip" -DestinationPath "$env:TEMP\eagle_m3" -Force
    Copy-Item -Path "$env:TEMP\eagle_m3\Eagle_M3\*" -Destination . -Recurse -Force
    Remove-Item .\APPLY_M3.txt

2. Remove the old prototype speech input (replaced by src\stt\):
    Remove-Item .\src\speechinput.cpp, .\src\speechinput.h

3. Build and test:
    cmake --build --preset windows-mingw-release
    ctest --preset windows-mingw-release
   (tst_whisperserverprocess is skipped on Windows; that is expected.)

4. Run:
    .\build\mingw-release\EagleGD.exe
   Readiness must show "whisper-server (speech to text)" = OK.

5. Commit when the manual checks pass:
    git add -A
    git commit -m "M3: speech input (whisper-server, VAD, incremental transcript, language auto/lock)"
